# urtir profile README — cyber maximalism

## Scope and mode
GitHub profile README (single surface). Mode: Experience + Persuade — portfolio identity for recruiters/peers; artifact leads, interface is markdown+badges.

## Audience, job, action, proof, constraints
- Audience: hiring managers, security/ML peers, open-source collaborators.
- Job: read stack, credibility, publications in seconds.
- Action: click portfolio / publications / repos.
- Proof: certs, papers, live stats, contribution graph.
- Constraints: GitHub sanitizes HTML (no CSS/style tags); skillicons only valid IDs; shields for tools skillicons lacks; keep facts from current README.

## Chosen direction and memorable moment
Direction: cyber-maximalism / terminal-brutalist sticker wall — acid green #00FF41, alert red #FF3333, magenta #FF00FF, caution yellow #FFE600 on #000000; hard rules, dense badge marquees, fixed-width stats grid, fixed-width research table. Memorable moment: first viewport is a full-width acid banner + stacked skill sticker wall, not a soft centered hero.

## Unresolved decisions
None — brief pins maximalism, stack fix, table width fix.

## Direction contract

THESIS: Profile as loud security-lab zine — density and clash over soft portfolio calm; refuses pastel centered "Hi I'm" hero.

OWN-WORLD: Pure black ground, acid green primary, magenta/yellow/red secondaries; badge stickers, thick ═ rules, mono screaming headers, hard-edged HTML tables with fixed widths, no gradients, no glass, no rounded pastel cards.

STORY: Visitor lands, reads who/what in one screen, scans stack stickers, certs wall, stats grid, papers table, leaves via portfolio link.

FIRST VIEWPORT: Centered unicode banner + one-line pitch + two hard CTA links; stack stickers begin immediately under a ═ STACK ═ rule — no whitespace cushion.

FORM: Single-file README maximalism; seed: gen-z-chaos-maximalism fused with cybersecurity-matrix palette (user-pinned maximalism beats roll).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
